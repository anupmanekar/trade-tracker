# Trade Tracker

A simple application to track your trades, monitor performance, and analyze trading strategies.

## Features

- Record buy/sell trades
- Track portfolio performance
- Visualize trade history
- Export data for analysis

## Getting Started

1. **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/trade-tracker.git
    cd trade-tracker
    ```

2. **Install dependencies:**
    ```bash
    uv sync
    ```

3. **Run the application:**
    ```bash
    uv run main.py
    ```
